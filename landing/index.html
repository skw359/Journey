How it works

From zero to first route in three steps.

1

Host Journey

Run the server on any Linux machine with Node, PostgreSQL and a reverse proxy. Your domain, your TLS, your rules.

2

Pair your devices

Open the dashboard, scan the pairing QR code from the iOS app, and your iPhone and Apple Watch are linked.

3

Just go

Hit Start. Routes, photos, speed and elevation flow to your server and land on your timeline and atlas.

Run it anywhere

Built for people who like owning their stack.

Journey isn’t a hosted service — it’s software you run. If you’re comfortable with a terminal, you’re minutes away.

Linux serverNode.jsPostgreSQL 16+Nginx + TLSffmpeg (optional, for video)

Step-by-step guide: documentation/GETTING_STARTED.md in the repository walks through server setup, the database, and your reverse proxy.

# install dependencies
$ npm install
$ cd client && npm install

# build the dashboard
$ npm run build

# start the server
$ npm start
